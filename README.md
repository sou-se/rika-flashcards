# 理科 フラッシュカード

理科の問題集（要点）をもとにしたフラッシュカードアプリです。
`index.html` 1ファイルで完結しています（外部ライブラリなし・オフライン動作）。

開くと単元を選ぶ画面が出ます。収録している単元：
- No.1 種子のつくりと発芽（要点 p.2〜7）
- No.2 種子の発芽とその条件（要点 p.8〜12）
- No.3 光合成と呼吸・植物の成長（要点 p.14〜19）

種子のつくり・発芽の実験・光合成の実験などは、問題の上に図（SVG）が出ます。

単元を追加するときは `index.html` の `ERAS` に1ブロック足します。
図が必要なカードは `FIG` に図を追加して、カードに `f: "図の名前"` をつけます。

## 使い方
- 単元を選ぶ → カードをタップして答えを確認 → 「覚えた」「まだ」で自己採点
- 終わったら「まだ」のカードだけをくり返し練習できます
- 「答え→問題」モードで逆向きの練習もできます（図つきカードは除く）
- 覚えた記録はブラウザに保存されます
