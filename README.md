# 小学五年サイエンス　理科要点のまとめ

理科の問題集（要点）をもとにしたフラッシュカードアプリです。
`index.html` 1ファイルで完結しています（外部ライブラリなし・オフライン動作）。

開くと単元を選ぶ画面が出ます。収録している単元：
- No.1 種子のつくりと発芽（要点 p.2〜7）
- No.2 種子の発芽とその条件（要点 p.8〜12）
- No.3 光合成と呼吸・植物の成長（要点 p.14〜19）
- No.4 根・茎のつくりとはたらき（要点 p.20〜23）
- No.5 葉のつくりとはたらき（要点 p.24〜27）
- No.7 こん虫のつくりと育ち方（要点 p.34〜40）
- No.8 メダカの育ち方（要点 p.42〜47）
- No.9 プランクトンと食物連鎖（要点 p.48〜55）
- No.10 太陽の動き（要点 p.56〜64）
- No.11 月の動きと満ち欠け（要点 p.2〜9）
- No.12 星と星座（要点 p.10〜15）
- No.13 星の日周運動（要点 p.16〜20）
- No.14 星の年周運動・星座早見（要点 p.22〜26）
- No.15 光の性質とはたらき（要点 p.28〜37）
- No.16 音の性質とはたらき（要点 p.38〜45）
- No.17 熱の性質とはたらき（要点 p.46〜53）
- No.18 酸素とその性質（要点 p.54〜59）
- No.19 二酸化炭素とその性質（要点 p.60〜65）
- No.20 ものの燃焼（要点 p.66〜71）
- No.21 もののとけ方（要点 p.2〜7）
- No.22 水溶液のこさ（要点 p.8〜13）
- No.23 溶解度・濃度計算（要点 p.14〜19）
- No.24 気温の変化と湿度（要点 p.20〜25）
- No.25 風のふき方と雲のでき方（要点 p.26〜31）
- No.26 天気記号・気団と前線（要点 p.32〜39）
- No.27 四大気団と日本の天気（要点 p.40〜45）

各単元の中は、テキストの大見出しの番号（1, 2, 3…）ごとに分かれています。
カードの左上に「No.1-3 種子のつくり（p.4〜5）」のように番号とページが出ます。

種子のつくり・発芽の実験・光合成の実験・根や茎や葉の断面・蒸散の実験などは、問題の上に図（SVG）が出ます。

単元を追加するときは `index.html` の `ERAS` に1ブロック足します（`decks` は大見出しごとに `no`・`title`・`page` をつける）。
図が必要なカードは `FIG` に図を追加して、カードに `f: "図の名前"` をつけます。

## 使い方
- 単元を選ぶ → カードをタップして答えを確認 → 「覚えた」「まだ」で自己採点
- 終わったら「まだ」のカードだけをくり返し練習できます
- 「答え→問題」モードで逆向きの練習もできます（図つきカードは除く）
- 覚えた記録はブラウザに保存されます
